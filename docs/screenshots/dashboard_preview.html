Portfolio value, TWR, XIRR, allocations

Honest state: total portfolio value, holdings allocation, and per-account TWR/XIRR series require core.report_snapshot rows (archived valuation/performance payloads). This deterministic demonstration pipeline archives 1 report snapshot(s); the full per-account performance series is populated by a broader snapshot run. Values are never fabricated; run the snapshot/performance pipeline, then refresh Power BI to populate marts.performance_summary and marts.holdings_snapshot.

  • Valuation rule: position = units × NAV + cash (Decimal/NUMERIC).
  • TWR: time-weighted, external flows only (GIPS-style conventions where documented).
  • XIRR: money-weighted, investor cash flows + terminal value.
  • Stale/missing NAV is reported separately; never silently forward-filled beyond policy.

## Qualification

No E9 distribution is claimed on the full path-window universe unless every eligible window has a valid root. Excluded rows remain in `results/sensitivity_detail.csv` with blank XIRR fields and are counted in the summary `failures` map; they are never averaged away.

The metric is **annualised XIRR minus period TWR over the same 12-month SIP window**. It compares two different return measures and is not an error metric.
