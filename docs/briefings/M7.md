## 1. What was built

- `src/bitemporal_ledger/invariants/invariants.py` — per-account invariant replay (positions derivable, units/cash non-negative Decimals, valuation priced). Stale-NAV limitations are counted, not failed.
- `scripts/reproduce.py` — deterministic pipeline: migrations → idempotent NAV import (raw-file fallback) → deterministic generator → ledger ingest → invariants → `RESULTS.md` (E1–E7). `make reproduce` / `make.ps1 reproduce` entry points added.
- `RESULTS.md` (generated) — E1–E7 evidence with dataset hash, invariant counts and limitations.

## 2. How it works

`make reproduce` from an empty database runs every step in order and must exit non-zero on invariant failure. From an already-populated database the same command is idempotent: migrations no-op, import reports `inserted=0`, and ingestion reports `skipped=2287`.
